## 🎬 What I'm building

- **[scene-studio](https://github.com/fviet297/scene-studio)** — Remotion pipeline that turns a Vietnamese history script into video: script, narration, images, motion, review panel. Made for my YouTube channel, Chuyện Cũ Kể Lại.
- **scene-studio-next** — a TypeScript rewrite of the studio as a local panel (script → narration → images → maps → MP4 render → posts & thumbnails), 337 tests. Private while in active development.
- **vietlott-server** — Keno crawler (Go) + FastAPI/SQLite analytics API + Telegram bot. Private.
- **[ef27](https://github.com/fviet297/ef27)** — Python bot that plays eFootball offline event matches vs COM, using screen automation (OpenCV + virtual gamepad). Offline only.
